Firebase verbinden (einmalig)

  1. console.firebase.google.com öffnen, Projekt erstellen (Analytics aus).
  2. Realtime Database erstellen, Standort Belgien (europe-west1), gesperrter Modus.
  3. Tab «Regeln» ersetzen durch: 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "games": {
      "$code": { ".read": true, ".write": true }
    }
  }
}
  4. Projekteinstellungen → Web-App </> registrieren → Block const firebaseConfig = {…} kopieren.
