Einrichtung (einmalig)

Damit die Handys der Lernenden mit deinem Laptop kommunizieren können, braucht die App eine kostenlose Firebase-Datenbank von Google.

Schritt für Schritt (ca. 15 Minuten)

  1. Öffne console.firebase.google.com und melde dich mit einem Google-Konto an.
  2. «Projekt erstellen» → Name z.B. klassenquiz → Google Analytics deaktivieren → erstellen.
  3. Links im Menü: Build → Realtime Database → «Datenbank erstellen». Standort: Belgien (europe-west1). Modus: «Im gesperrten Modus starten».
  4. In der Datenbank den Tab «Regeln» öffnen, alles ersetzen durch den folgenden Text und «Veröffentlichen»: 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "games": {
      "$code": { ".read": true, ".write": true }
    }
  }
}
  5. Links oben auf das Zahnrad → Projekteinstellungen. Unten bei «Meine Apps» auf das Symbol </> (Web) klicken → Name eingeben → «App registrieren» (Hosting nicht anhaken).
  6. Es erscheint ein Code-Block mit const firebaseConfig = { ... }. Diesen ganzen Block kopieren und hier unten einfügen.
